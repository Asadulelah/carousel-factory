# meet-the-factory - carousel spec

- **Idea:** introduce carousel-factory by being made by it (the demo is the proof)
- **Audience:** creators and builders tired of manual design tools
- **Worthiness check:** meta-demo, shows the output quality while explaining the pipeline
- **Slide structure:**
  1. Hook: handmade vs factory
  2. The pipeline (4 steps)
  3. Why HTML beats design tools (systems > moods)
  4. The machinery (130 lines, headless browser)
  5. The honest split: human parts vs automated parts
  6. Close: clone it, theme it, ship daily + repo link
- **Theme:** near-black / bone / terracotta accent, Bricolage Grotesque + Spectral italic
